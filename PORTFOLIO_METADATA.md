## Rules this table follows

- A description states what the project does and whose data it uses. Synthetic and generated data is labeled in the description itself, not only in the README.
- Topics are lowercase and evidence-backed: a tool is listed only when the repository uses it.
- A homepage points only at something live: a published Tableau workbook or a hosted page. It stays empty otherwise.
- Licenses are left as they are. Eleven repositories carry no license file; adding one grants rights and is a deliberate choice, not a cosmetic one.
